# 🧱 VibeTravels Tech Stack Overview

## 🎨 Frontend
- **Blazor Server** as the complete frontend framework on the .NET platform  
- **Bootstrap** for CSS styling

## ⚙️ Backend
- **ASP.NET 8.0**  
- **MS SQL Server** as the database  
- **Entity Framework Core** for ORM and data access

## 🤖 AI Integration
- Communication with models via **Openrouter.ai**  
  - Access to a wide range of models (OpenAI, Anthropic, Google, and many others), enabling high efficiency and low cost solutions  
  - Ability to set financial limits on API keys

## 🚀 CI/CD and Hosting
- **GitHub Actions** for building CI/CD pipelines  
- **DigitalOcean** for hosting the application via Docker image
